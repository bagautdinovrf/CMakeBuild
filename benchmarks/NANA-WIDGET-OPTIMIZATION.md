# Проверка элементов NanaPlus 1.9.3 — 2026-10-07

Проверены элементы, которые использует панель: формы, кнопки, журнал и поля
настроек, обе полосы прокрутки, меню, выпадающие списки, подписи, checkbox,
контейнеры и таймеры. Изменения сосредоточены в повторяющихся измерениях текста
и отрисовке. Библиотечные исправления находятся в форке NanaPlus; CMake
проверяет закреплённый архив и собирает его исходники без патчей.

| Элемент | Изменение или результат проверки |
| --- | --- |
| Журнал / textbox | Положение текста и значения обеих полос восстанавливаются вместе. Append и обрезка старых строк показываются после восстановления просмотра и выделения. Координата строки без переноса вычисляется напрямую. |
| Полосы прокрутки | Обработчик отрисовки устанавливается один раз; неизменные цвета и масштаб не вызывают обновление. Длины полос сходятся в общем углу при разных отступах. Угол окрашен цветом дорожки текущей темы. |
| Меню | Размеры пунктов кэшируются между наведениями. Текст, состав, шрифт, DPI, рендерер и ограничения размеров инвалидируют кэш. Размещение на экране проверяется каждый раз. |
| Формы и кнопки | Изменения состояния и палитры объединяются перед показом. Неизменившийся тик таймера не обновляет виджеты; анимация прогресса сохраняется. |
| Поля настроек | Сразу применяются конечные отступы вместо промежуточного снятия и повторного расчёта переноса. |
| Выпадающие списки | Сохранены настоящие popup, выбор и рендереры. Проверяется полный текст, геометрия и callbacks в двух темах на четырёх масштабах. |
| Подписи / checkbox / контейнеры | Используют общее объединение смены палитры и пропуск повторного назначения того же шрифта; жизненный цикл и обработка ввода сохранены. |
| Общие шрифты и графика | Одинаковый разрешённый шрифт не вызывает повторный пересчёт редактора, настройку контекста и измерение пробелов/табуляции. Реальная смена шрифта и DPI сохраняет пересчёт. |
| Unicode | Исправлены валидатор UTF-8 и преобразование supplementary-символов, чтобы emoji и следующий текст участвовали в выводе и измерении целиком. |

Следование журналу автоматическое: при просмотре конца без выделения новые
строки остаются видимыми. Просмотр старых строк или выделение удерживает
текущий участок; возврат в конец без выделения возобновляет следование.
Проверка промежуточного составного буфера окна обнаруживает даже краткий
показ конца журнала перед возвратом к читаемому месту.

`api::batch_updates` предназначен для синхронных изменений на GUI-потоке.
Внутри callback нельзя запускать вложенный цикл событий, модальный диалог
или принудительную немедленную отрисовку. Обычные обновления виджетов,
вложенные порции и исключения проверяются отдельной регрессией.

## Методика измерения

Сравнивается сохранённый Release EXE до оптимизации с окончательной сборкой
той же панели 1.9.3. Базовая библиотека — commit
`4484572480c4c190029a3107856ab30029af6d13`, уже содержащий первоначальную
синхронизацию ползунков. Нагрузка: 128 пакетов по 64 строки, Unicode,
обрезка журнала, 64 полные перерисовки и 32 смены палитры, 120 DPI.
Результаты относятся к совокупности изменений и этой машине.

Меню измеряется отдельно: один и тот же код фикстуры, связанный с сохранённой
и новой статической библиотекой; 2000 наведений на 24 длинных пункта.
Порогов производительности в тестах корректности нет.

## Результат

Четыре чередующиеся пары процессов, первая — прогрев. Ниже медианы трёх
измеряемых запусков; это описательные результаты короткой серии.

| Метрика | До | После | Изменение |
| --- | ---: | ---: | ---: |
| Все 128 пакетов журнала, мс | 1010,70 | 920,12 | −9,0% |
| CPU обработки журнала, мс | 1000,00 | 906,25 | −9,4% |
| Пакет журнала p95, мс | 9,42 | 8,05 | −14,6% |
| Полная перерисовка p50, мс | 3,61 | 3,51 | −2,6% |
| Смена палитры p50, мс | 10,49 | 7,81 | −25,6% |
| Private Bytes после журнала, MiB | 18,93 | 18,81 | −0,7% |
| 2000 наведений меню, мс | 2370,26 | 2391,21 | +0,9% |

Все измеренные пары обработки журнала и смены палитры p50 стали быстрее.
Для меню диапазоны перекрываются: 2338–2434 мс до, 2367–2594 мс после;
устойчивое ускорение полной отрисовки меню эта серия не подтверждает.
Кэш устраняет повторные измерения подписей, но полная отрисовка остаётся.
Разница полной перерисовки и памяти мала относительно разброса.
CPU в простое во всех запусках — ниже чувствительности интервала 1,5 секунды.

[Агрегат и исходные измерения](results/nana-widgets-1.9.3/report.json)
содержат значения каждого запуска, диапазоны, хеши EXE и проверенный Git tree.
В сырых данных `toolkit_revision` остался исходным pin: замер новой библиотеки
сделан через локальный source override до заключительной публикации. Поле
`tested_final_source_tree` однозначно определяет измеренные исходники;
публичный архив должен содержать то же дерево.

## Проверки корректности

Прошли восемь наборов CTest: контроллер, UI, DPI, редактор, отложенная очистка,
объединение обновлений, меню и Unicode. Тест объединения обновлений проверяет
также настоящий Windows event, вложенные изменения из отрисовки прозрачного
виджета, исключения и удаление окна. Валидатор сравнивается с Win32 на всех
одно- и двухбайтовых входах и повреждённых последовательностях у границ Unicode.

40 обычных кадров панели и настроек до и после оптимизации совпали по всем
пикселям. Отдельная матрица из восьми снимков журнала проверяет исправленный
стык полос, полную видимую площадь угла и смежные края в двух темах на
100/125/150/200%. У borderless-редактора штатная нижняя строка полосы выходит
на один пиксель за границу виджета и обрезается; тест явно учитывает это.

Исходники библиотеки, на которых выполнены проверки и измерения, имеют Git tree
`6feaee56faa87f9e8ce0d97cbe2fb982540eaca2`. Окончательный публичный commit и
SHA256 его архива записаны в [nana.cmake](../nana/cmake/nana.cmake).

Готовый `nana/CMakeBuild.exe` собран из закреплённого архива: 1 664 000 байт,
FileVersion/ProductVersion **1.9.3**, SHA256
`3f92d84992095602dfa5e9c3a62cd14cfe809f8b9b98a356fc9e366855ec1ee5`.
Основной FLTK EXE также имеет общую версию 1.9.3. INI не изменился во время
тестов и измерений; изменения координат, сделанные открытой пользователем
панелью вне этих интервалов, сохранены.
