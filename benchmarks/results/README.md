# Опубликованные серии бенчмарков

Здесь сохранены portable snapshots трёх проверенных серий:

- [11:28, Nana 1.8.4 до оптимизации](20261006-112824-363-137d720f/report.md).
- [12:16, промежуточная оптимизация](20261006-121653-915-baa3a1ee/report.md).
- [12:25, итоговая Nana 1.8.5](20261006-122510-496-50f3b2e6/report.md).

В каждой папке находятся `report.md`, `report.csv` и `report.json`. JSON
содержит все измеренные процессы, прогревы и исходные выборки операций;
отдельные JSON процессов не дублируются. Числовые значения, геометрия,
тайминги, CPU/RAM/Windows, компилятор и SHA256 программ сохранены без изменений.

В публикационных JSON персональные пути заменены относительными путями или
portable placeholders. Путь пользовательских настроек обозначен через
`%LOCALAPPDATA%`; отпечатки и размер реального INI удалены, факт
`settings.unchanged=true` сохранён. `embedded:report.json#/.../document`
указывает на включённый в отчёт JSON процесса. Журналы stdout/stderr, INI,
EXE и файлы сигналов первой отрисовки не публикуются вместе с данными.

Оригинальные отчёты в `build/engine-tests/benchmarks` не изменялись.
Интерпретация результатов: [исходная серия](../RESULTS.md) и
[итоговая оптимизация](../NANA-OPTIMIZATION.md).
